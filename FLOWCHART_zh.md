# Logstash Forwarder Java - 高级流程图

```
[开始]
  |
  V
应用程序启动
  |
  V
解析命令行选项 (例如, -config, -spool-size, -idle-flush-time)
  |
  +---------------------> [ 是否有 -config 选项? ] --否--> 使用默认配置文件路径 ("logstash-forwarder.conf")
  |                             | 是
  |                             V
  |                       使用指定的配置文件路径
  |                             |
  |<----------------------------+
  |
  V
加载配置文件 (JSON)
  |
  V
[ 配置文件有效? ] --否--> 记录错误并退出
  | 是
  V
解析配置:
  - 网络设置 (主机, 端口, SSL CA证书, 超时)
  - 监控的文件 (路径, 字段)
  |
  V
初始化 FileWatcher (文件观察器)
  |
  V
加载 Sincedb 状态 (例如, ".logstash-forwarder")
  - 对每个配置文件, 获取最后已知字节偏移量
  |
  V
初始化 LumberjackClient (Lumberjack客户端)
  |
  V
尝试连接到 Logstash 服务器 (使用配置中的网络设置)
  |
  +------> [ 连接成功? ] --否-------------------------------------+
  |               | 是                                                         |
  |               V                                                            |
  |       记录 "已连接到 Logstash"                                           |
  |                                                                            |
  |<-------------------------------------- 主要处理循环 <----------------------+
  |                                         (周期性执行, 例如每秒一次)         |
  |                                                                            |
  |  [ stdin 是否配置为被监控? ] --是--> 检查 stdin 中是否有新行               |
  |    | 否                                           |                       |
  |    V                                              V                       |
  |  检查被监控文件是否有修改 (通过 FileWatcher)                               |
  |    |                                                                       |
  |    +-----> [ 是否有文件被修改或 stdin 有新行? ] --否--> 延迟后循环返回再次检查
  |              | 是                                                        |
  |              V                                                           |
  |            对于每个修改过的文件 (或 stdin):                               |
  |              - 从最后已知偏移量读取新的日志行                              |
  |              - 将行添加到当前事件批次 (spool)                             |
  |              - 更新文件的字节偏移量                                        |
  |                                                                          |
  |  [ 批次大小 > 0 且 (批次已满 (spool size) 或达到空闲刷新时间)? ] --是--> 发送批次
  |    | 否                                                                      |
  |    +-------------------------------------------------------------------------+
  |                                                                              |
  | 发送批次到 Logstash (通过 LumberjackClient):                                |
  |   - 准备 Lumberjack 有效载荷 (窗口大小 = 批次大小, 压缩数据)                |
  |   - 发送数据帧                                                              |
  |   |                                                                          |
  |   V                                                                          |
  | [ 数据发送成功? ] --否-------------------------------------------> [ 处理发送错误 ]
  |   | 是                                                                         |
  |   V                                                                            |
  | 等待 Logstash 的确认 (ACK)                                                 |
  |   |                                                                          |
  |   V                                                                          |
  | [ 收到 ACK 且与窗口大小匹配? ] --是--> 用已确认文件的新偏移量更新 Sincedb 状态
  |   | 否 (超时或不匹配)                                                      |
  |   V                                                                          |
  | [ 处理 ACK 错误/超时 ]                                                     |
  |   - 记录错误                                                                 |
  |   - 可能重发批次或标记为失败 (取决于错误类型)                                |
  |   - 如果连接丢失, 触发重连序列                                               |
  |   |                                                                          |
  |   +--------------------------------------------------------------------------+
  |                                                                              |
  | 循环返回到主要处理循环 ------------------------------------------------------>
  |
  V
[ 处理发送错误 ] / [ 发送/ACK 期间连接丢失 ]
  |
  V
记录错误 (例如, "与 Logstash 的连接丢失")
  |
  V
尝试重新连接到 Logstash (使用退避/重试机制)
  |
  +-----> [ 重连成功? ] --否--> 继续重试 (增加延迟时间) / 记录失败
  |         | 是
  |         V
  |       记录 "已重新连接到 Logstash"
  |         |
  |         +--------------------------------> 循环返回到主要处理循环 (以重发或继续)
  |
[结束] (通常无限期运行, 直到被中断, 例如 Ctrl+C)
```
